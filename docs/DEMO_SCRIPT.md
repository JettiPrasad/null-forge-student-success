# Four-Minute Demo Script

## 0:00–0:30 — Problem
Introduce the Student Success Analytics Platform. It combines academic, attendance, LMS, engagement, placement, skills and feedback data into one student-review workflow.

Clarify that the Student Success Score is a rule-based prototype, not a validated prediction model.

## 0:30–1:15 — Overview
Show the total student count, scored students, average score and risk distribution.
State that the current demo cohort has 15 unchanged source records and 85
generated demonstration records. Read values from the currently verified build
rather than quoting fixed metrics in this script.

## 1:15–2:00 — Student explorer
Search for a student by name or ID and demonstrate the risk filter. Open a profile and explain the score, data coverage, domain breakdown, risk flags and score drivers.

Show that missing measurements reduce coverage instead of being automatically treated as zero.

## 2:00–2:45 — Integrated source data
Show the source-data section, Skills & Portfolio, and Placement Activity panels
of a student profile. Explain how categorical skills, projects,
certifications, training, and applications are useful recorded evidence without
being relabelled as missing numeric assessments.

Demonstrate placement activity review. Interest, training, internship status, applications and offers can guide follow-up, but they are not substitutes for missing aptitude, coding or mock-interview scores.

## 2:45–3:30 — Explainability
Explain the configured weights and rule-based thresholds. Show why an indicator was raised and which available measurements contributed to the analysis.

Emphasize that the dashboard supports human review and should not be the sole basis for high-impact student decisions.

## 3:30–4:00 — Validation and close
Show the automated verification commands and explain that the prototype uses a
demo cohort with missing values. Close by summarizing how the unified dashboard
helps reviewers inspect available student indicators.
